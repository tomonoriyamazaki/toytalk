# ToyTalker TIB FAB 展示動画シリーズ — 制作指示書

## このドキュメントについて

claude.ai 上で作成した「応答速度」説明動画のプロトタイプ(`toytalker_response_speed.mp4` + `render.py`)を出発点に、TIB FAB 展示用の動画6本シリーズを制作するためのプロジェクト指示書。Claude Code に渡して、Remotion ベースの共通テンプレートプロジェクトとして立ち上げることを想定している。

## 背景と展示条件

- ToyTalker(AI会話デバイス)の TIB FAB 展示ブースで流す説明動画シリーズ
- **音声なし(サイレント再生)+ 字幕前提**。字幕の視認性が最重要
- 各動画は**単体ループ再生**を想定。終端→先頭が自然につながるようフェードで処理する
- 通しで流す場合の全体構成は以下(数字は秒数):

| # | セクション | 尺 | 形式 | 状態 |
|---|----------|----|------|------|
| 1 | 会話 | 30 | 実写動画 | 別途撮影 |
| 2 | コンセプト | 15 | アニメ | 本プロジェクトで制作 |
| 3 | 応答速度 | 15 | アニメ | **プロトタイプ済み(本書のベース)** |
| 4 | 声変え | 15 | アニメ | 本プロジェクトで制作 |
| 5 | 製作 | 30 | 実写動画 or アニメ | 検討中 |
| 6 | 操作 | 25 | 実写動画 or アニメ | 検討中 |

※ 実写パートは DaVinci Resolve で編集。本プロジェクトの担当はアニメパート(2, 3, 4 を優先)。実写パートにも字幕・テロップの共通スタイルを流用したいので、字幕デザインはトークンとして独立させておくこと。

## 技術構成の指定

- **Remotion**(React + TypeScript)で制作し、mp4 を出力する
- プロトタイプは Python PIL + ffmpeg 製(`render.py` 同梱)。これは仕様書として参照し、Remotion に移植する
- 共通仕様:
  - 解像度 **1920×1080**、**30fps**
  - 各動画の尺は上表に従う(フレーム数 = 秒 × 30)
  - 末尾 0.8 秒でフェードアウトし、ループ時に先頭へ自然に戻す
  - コーデック: H.264、`-crf 18` 相当の高品質、`faststart`
- プロジェクト構造の提案:

```
toytalker-videos/
├── src/
│   ├── theme.ts              # カラー・フォント・字幕スタイルのトークン
│   ├── components/
│   │   ├── Subtitle.tsx      # 共通字幕(番号付きキャプション)
│   │   ├── StageCard.tsx     # パイプライン段カード(STT/LLM/TTS/デバイス)
│   │   ├── Pill.tsx          # チャンクピル(テキスト/音声/再生中の3状態)
│   │   └── Waveform.tsx      # 再生中の波形バーアニメ
│   ├── videos/
│   │   ├── ResponseSpeed.tsx # 3. 応答速度(最初に移植)
│   │   ├── Concept.tsx       # 2. コンセプト
│   │   └── VoiceChange.tsx   # 4. 声変え
│   └── Root.tsx
├── assets/                   # 実機写真・ロゴ等
└── reference/
    ├── render.py             # PILプロトタイプ(タイミングの正)
    └── toytalker_response_speed.mp4
```

## デザインシステム(プロトタイプ準拠)

`theme.ts` に以下をトークン化する。

### カラー

| 用途 | Hex |
|------|-----|
| 背景 | `#0F1220` |
| カード(非アクティブ) | `#1A1E30` |
| カード(アクティブ) | `#232048` |
| ボーダー(通常) | `#2A2F48` |
| アクセント紫(アクティブ枠・カーソル) | `#7F77DD` |
| テキスト(主) | `#ECEDF5` |
| テキスト(副) | `#9AA0B8` |
| ピル・テキストチャンク(塗り/文字/枠) | `#3C3489` / `#CECBF6` / `#534AB7` |
| ピル・音声チャンク(塗り/文字/枠) | `#085041` / `#9FE1CB` / `#1D9E75` |
| ピル・再生中(塗り/文字) | `#1D9E75` / `#E1F5EE` |
| 強調ティール(まとめ画面の大見出し) | `#9FE1CB` |

※ 将来 ToyTalker ブランドカラーが確定したら theme.ts の差し替えだけで全動画に反映できるようにする。

### タイポグラフィ

- フォント: **Noto Sans CJK JP**(Regular / Bold)
- サイズ(1080p 基準):
  - タイトル 46px Bold / ステージ名 40px Bold / 本文 38px / ピル 34px / レーンラベル 30px / 補足 28px
  - **字幕キャプション 48px Bold**(下部中央、角丸背景 `#1A1E30` 90% 不透明、左右パディング 40px)
  - まとめ画面: 大見出し 72px Bold、前後行 40px
- 展示では 2〜3m 離れて見る想定。字幕は 48px を下限とし、必要なら 56px まで上げられるよう変数化する

### モーション

- 要素の出現: opacity 0→1 + 上方向 18px スライド、cubic ease-out 0.35 秒。Remotion では `spring()` に置き換えて自然にしてよい
- タイピング(文字送り): 等速で 1 文字ずつ
- ストリーミングカーソル: `▍` を 1Hz 点滅
- 再生中波形: 4 本バー、`sin(t*7 + i*1.1)` の高さ揺れ(Waveform.tsx として共通化)

## 動画3「応答速度」タイムライン(15.0 秒 / 450 フレーム)

プロトタイプ mp4 と完全一致させること。`render.py` が正。

### 画面レイアウト

- 上部: タイトル「応答速度のしくみ — すべてを並行に、待たない設計」
- その下: 4 ステージカード横並び(STT 音声認識 / LLM 返答生成 / TTS 音声合成 / デバイス 再生)、間を「→」で接続。カードは 400×150px、ステータス行つき
- 中段: 4 レーン(ユーザー発話 / LLM ストリーム / TTS キュー / デバイス再生)、ラベル左、区切り線あり
- 下部: 字幕キャプション

## Remotion 移植時の改善要望

1. 出現アニメを `spring()` ベースにしてヌルヌルさせる(タイミングの開始時刻は表の通り厳守)
2. デバイスカード内に **ToyTalker Mini の実機写真**をはめ込めるようにする(assets/ に写真を置いたら差し替わる作り。写真は後日支給)
3. 波形バーをピル内に統合し、再生中ピルの見た目をリッチに
4. 字幕コンポーネントは切り替え時にクロスフェード(0.3 秒)
5. 尺・fps・字幕サイズは Root.tsx の合成定義で一元管理

## 動画2「コンセプト」/ 動画4「声変え」の方向性メモ(詳細は別途相談)

- **コンセプト(15秒)**: 「ぬいぐるみが、話し相手になる。」を軸に、デバイス写真+短いコピーが順に出るシンプルなモーションタイポグラフィ。パイプライン図は出さない
- **声変え(15秒)**: 同じセリフの吹き出しが、VOICEVOX キャラ声 → クローン音声(家族の声)と切り替わる様子を波形の色変化で表現。「声もえらべる。つくれる。」で締め
- いずれも共通コンポーネント(Subtitle / Pill / Waveform)を流用する

## 進め方

1. `reference/render.py` と mp4 を確認し、Remotion プロジェクトを scaffold
2. ResponseSpeed.tsx をタイムライン表どおりに移植 → mp4 出力してプロトタイプと見比べ
3. 改善要望 1〜5 を適用
4. Concept / VoiceChange の絵コンテを提案 → 合意後に実装
